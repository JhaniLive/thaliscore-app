# NutriScan

Scan a barcode, a nutrition label or your plate, and get a clear A to E grade with a plain answer on how often to eat it. Made for Indian packaged food and dishes.

## Install
1. On your Android phone (Android 8 or newer), open the download link above.
2. Open `NutriScan.apk`. If asked, allow your browser to install unknown apps.
3. Tap **Install**, open NutriScan and allow the camera.

This repository holds the website (`docs/`, served by GitHub Pages) and the APK releases.
